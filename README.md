# QuickNotes App

QuickNotes is a fast, simple note-taking web app that helps you capture ideas quickly. You can add notes under Personal, Work, or Study categories, search through them, and keep them saved even after refreshing.

## Features
- Add notes with category (Personal, Work, Study)
- Color-coded categories with left border
- Delete individual notes
- Live search filter
- Note count updates (no notes, 1 note, N notes)
- Validation for empty and >200 characters
- LocalStorage persistence
- Responsive design (mobile friendly)
- Bonus: Clear All button

## How to Run Locally
1. Clone the repo: `git clone https://github.com/abdulwahabuakim-spec/quicknotes-app.git`
2. Open `index.html` in your browser
3. Start adding notes
